## Sport Center
This project is a dynamic website that offers information on various fitness activities and programs while also promoting fitness. 
Users are able to peruse a number of categories, such as stretching routines, yoga, solo exercises, and group fitness. 
The website also offers a BMI calculator to help users keep track of their fitness progress.
### Description
Customers will be able to explore different exercise routines, learn about upcoming classes, and receive their BMI on an interactive platform with the assistance of the Sport Center Website Project. 
By giving them access to helpful resources and knowledge about fitness and wellbeing, it hopes to inspire individuals to live healthy lives.
### Features
- #### Scrolling Navigation Bar:
  The navigation bar's background color changes to create an eye-catching visual experience as a user navigates the page.
- #### Dynamic Content Display:
  Users can choose from a variety of categories to dynamically display pertinent information, including yoga, individual workouts, group fitness, and stretching routines.
- #### BMI Calculator:
  Users can find their Body Mass Index and monitor their level of fitness by inputting their height and weight into the website's BMI calculator.
- #### Mobile-Friendly Navigation:
  The navigation bar is simple to use on a range of screen sizes thanks to its mobile device optimization.
